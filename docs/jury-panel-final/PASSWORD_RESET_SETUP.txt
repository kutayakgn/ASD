JÜRİ ŞİFRE SIFIRLAMA KURULUMU

Ham token veritabanına yazılmaz; 32 baytlık rastgele tokenın yalnızca SHA-256 özeti saklanır. Token beş dakika geçerlidir. Yeni istek önceki açık tokenları, başarılı şifre değişikliği de kullanıcıya ait tüm açık tokenları geçersiz kılar. GET tokenı tüketmez. E-posta sabit boyutlu arka plan kuyruğundan gönderildiği için HTTP yanıt süresi posta kutusunun varlığına göre değişmez.

UYGULAMAYA EKLEME

1. Controller/service/context/entity/view-model dosyalarını ilgili proje klasörlerine taşıyın.
2. CSHTML dosyalarını Views/JuryVoting/, iki JavaScript dosyasını wwwroot/js/ altına taşıyın.
3. Tablo admin projesindeki V1_2_8_AddJuryPasswordResetTokens EF Core migration'ı tarafından yönetilir. Admin uygulaması açılışındaki DatabaseMigrationHostedService bekleyen migration'ı otomatik uygular; ayrıca SQL çalıştırmayın.
4. Admin ve jüri uygulamalarının aynı veritabanı/şema için doğru connection string kullandığını doğrulayın.
   Admin uygulamasının şirket ortamındaki DB kullanıcısı mevcut otomatik migration sistemi için gereken CREATE/ALTER TABLE, INDEX ve TRIGGER yetkilerine sahip olmalıdır; yetki yoksa uygulama güvenli biçimde başlangıçta hata verir.
5. Servis kaydına builder.Services.AddJuryPasswordReset(builder.Configuration); ekleyin.
6. Routing sonrasında, endpoint eşlemesinden önce app.UseRateLimiter(); çağırın.
7. appsettings_content.txt bölümünü ayarlara ekleyin. PublicBaseUrl üretim HTTPS adresi olmalıdır.
8. ClientSecret değerini repoya yazmayın. Secret store/ortam değişkeni adı:
   JuryVotingPasswordReset__MicrosoftGraphMail__ClientSecret

OUTLOOK / MICROSOFT 365 GÖNDERİCİ BİLGİLERİ

- Gönderici posta kutusu adresi (FromEmail) ve Exchange'deki görünen adı.
- Microsoft Entra tenant ID.
- Entra uygulaması client/application ID.
- Client secret (tercihen ileride sertifika/federated credential; secret store içinde).
- Tercih edilen yetki: Exchange Online Application RBAC ile yalnızca gönderici posta kutusuna scope edilmiş Application Mail.Send. Aynı uygulamaya ayrıca tenant genelinde Entra Mail.Send vermeyin; izinler birleşerek scope'u etkisiz bırakabilir.
- Eski alternatif: Entra Mail.Send application izni + yönetici onayı + aynı uygulamayı bu mailbox ile sınırlayan Application Access Policy.

Posta kutusu parolası gerekmez. Kurumsal Microsoft 365/Exchange Online varsayılmıştır. Kişisel @outlook.com hesabı kullanılacaksa app-only yerine delegated OAuth tasarlanmalıdır.

GÜVENLİK / İŞLETİM

- Kayıtlı ve kayıtsız e-posta için yanıt aynıdır.
- IP başına 5 dakikada 5, hesap başına 60 saniyede 1 istek sınırı uygulanır.
- URL sabit config'den üretilir; Host başlığına güvenilmez.
- Reset cevapları no-store/no-referrer/noindex kullanır; JavaScript tokenı adres çubuğundan temizler.
- Ham token, e-posta ve parola loglanmaz. Reverse proxy/access loglarında token query parametresini ayrıca maskeleyin.
- Admin audit trigger üretimi JuryPasswordResetTokens tablosunu özellikle hariç tutar; yüksek entropili token özeti uzun süreli AdminLogs kayıtlarına kopyalanmaz.
- Proxy arkasında yalnızca güvenilen proxy'ler için forwarded headers yapılandırın.
- In-memory kuyruk süreç yeniden başlarsa bekleyen mesaj kaybolabilir; kullanıcı 1 dakika sonra tekrar isteyebilir. Kalıcı teslim garantisi istenirse kuyruk arayüzünü şifreli transactional outbox ile değiştirin.
- Kullanılmış/süresi dolmuş token kayıtlarını örneğin 7 gün sonra periyodik job ile temizleyin.
- Paketteki PasswordHashHelper yeni parolaları sürümlü PBKDF2-SHA256/600.000 iterasyonla saklar. Eski PBKDF2-SHA1/10.000 kayıtları yalnızca geçiş amacıyla doğrular ve ilk başarılı girişte otomatik yükseltir; hedef sistemin legacy formatı farklıysa VerifyLegacy buna göre uyarlanmalıdır.
- Mevcut login görünümü TempData["ResetPasswordSuccess"] mesajını göstermelidir.
- Uygulamadaki mevcut özel session yapısı aktif oturumları parola değişince kendiliğinden düşürmüyorsa, User üzerinde bir session/password version tutup her jury isteğinde doğrulayın ve reset transaction'ında bu sürümü yenileyin. ASP.NET Identity kullanılıyorsa security stamp güncellemesiyle aynı sonucu alın.
